# 引継ぎ: 小学コレ 動画撮影（実機テスト用セッション向け）

作成: 2026-10-08 / 前提: 先に `引継ぎ_小学コレ実機テスト_2026-10-08.md`（端末・adb・作業フォルダ・スクリプトの罠）と、`shared_core/docs/DEV_PLAYBOOK.md`（正本）を読む。

## 0. 目的
小学コレの**各教科**について、次の2つに使える動画を作る。
1. **Google Play の掲載用**（プロモ動画。YouTube の URL を Play に登録する。一般公開または限定公開・広告オフ・年齢制限なし）
2. **X 投稿用**（4:5 の動画ファイルを直接添付。添付と投稿はユーザー本人）

ユーザーの要望: 「**キャラの獲得やレベルアップなどで、モチベーションを上げられる**」ことを動画に含めたい。

## 1. 方式の推奨（結論）
**ハイブリッド方式**: 実機の短い画面録画（動きのある場面だけ）＋ 既存テンプレートで編集（見出し・BGM・アウトロ）。

| 方式 | 良い点 | 弱い点 | 判断 |
|---|---|---|---|
| A. 全部を画面録画 | 本物の動き・演出が出る | 教科ごとに長い撮影・台本が要る。見出しや統一感が出ない | 単独では不採用 |
| B. スクショ紙芝居（現行。`sns\ツール\vertical_video\make_vertical.py`） | 速い。見た目が揃う。端末不要 | 動きがない。**キャラ獲得・レベルアップの演出が伝わらない** | モチベーション場面には不足 |
| C. アプリ内のデモモード/integration_test で自動再生して録画 | 再現性が高い | 実装コスト大（全アプリに入れる必要） | 将来案 |
| **D. ハイブリッド（A の短クリップ＋B のテンプレ）** | 動きが必要な所だけ撮れば足りる。見出し・BGM・アウトロは全教科で共通 | クリップ取り込みの編集機能を `make_vertical.py` に足す必要あり | **推奨** |

- 全教科共通の構成（案・約30秒）: ①フック（3秒）→ ②学ぶ（問題→正解→解説。紙芝居でよい）→ ③**やる気（実機クリップ 4〜6秒）: キャラ獲得／レベルアップ／バッジ／連続日数** → ④保護者（ダッシュボード）→ ⑤アウトロ（アプリ名・広告なし・14日無料・Google Play）。
- 出力は2種: **9:16 (1080×1920)**＝Play プロモ（YouTube）・Shorts・リール・TikTok、**4:5 (1080×1350)**＝X。
- 音声は自作BGM・効果音（`make_vertical.py` の `make_audio`）。外部素材は使わない（ライセンス不要）。
- まず**1教科でパイロット**（おすすめ: 国語。キャラ獲得画面「ホンホン」の元スクショが既にあり、実機にも入っている）→ 他教科へ展開。

## 2. 撮りたい「やる気」場面（教科ごと。要確認が多い）
| 教科 | 撮りたい場面 | 備考 |
|---|---|---|
| 算数 | バッジ獲得（はじめての算数・満点！・学習スタート）、キャラ育成（コインで）、毎日ボーナス・週替わりチャレンジ、連続日数 | 結果画面の元スクショあり |
| 国語 | **新しいキャラクターをゲット**（ホンホン）、16種のアバター、バッジ、連続日数、書き順アニメ | `01_raw\06_character.png` あり |
| 社会 | 連続日数、学習履歴、ランキング（対戦は無効化中。実際に動くか要確認） | キャラ要素は要確認 |
| 理科 | 理科博士コレクション（16キャラ）、今日のプレゼント、デイリー、バッジ、生き物図鑑 | 画面崩れ・テスト名「てst」に注意 |
| 英語 | ペット育成、Lv・XP、バッジ、連続日数 | 設計は「ペット育成＆先生ごっこ」 |
| 心身 | アバター（16体×Lv1〜5の進化）、バッジ、道徳ストーリー、スポーツずかん | 画像は Leonardo 生成済み |

- 「レベルアップ」「キャラ獲得」を**短時間で起こす**には、テスト用プロフィールにコインや進捗を入れる必要がある場合がある。**本番データではなくテスト用のプロフィール**で行い、アプリのコードを変えて撮らない（変えるなら別ブランチ・コミットしない）。

## 3. 撮影の手順（プレイブック §7 に準拠）
```bash
SC=/c/Users/zka32/.claude/shared_core/.claude/skills/ship-cycle
export ANDROID_SERIAL=2e02b56b                  # 端末固定（2台つながっていることがある）
bash $SC/device-10check.sh demo on              # ステータスバーを 9:41・電池100% に固定
bash $SC/device-10check.sh record 20 kokugo_character OUT=<出力dir>   # 画面録画（最大180秒・4Mbps）
bash $SC/device-10check.sh demo off
```
- 画面録画は `adb shell screenrecord`。録画ファイルは `adb pull`（スクリプトが処理）。**スクショは `adb exec-out screencap -p`**（`shell screencap` はPNGが壊れる）。
- **debug ビルドは使わない**（右上の DEBUG バナー、はみ出し警告 "OVERFLOWED BY…" が映る）。**release か profile のビルド**で撮る（署名なしの端末ローカル用でよい。`flutter build apk --profile` が使えるかは要確認）。
- 端末は**明るいテーマ**に（暗いテーマだと、ストア・X の他の画像と見た目が合わない）。設定の変更は、ユーザーの了承を取ってから。
- プロフィール名は、テスト名（「Test」「てst」）を映さない。「はな（小学1年生）」「たろう」など、自然な名前にする。
- 実機は共用。操作前に前面アプリを確認。無線 adb のポートは変わる。
- 録画は**1場面ずつ短く**（4〜8秒）。タップはゆっくり、画面が切り替わったら1秒止まる。

## 4. 保存先・命名
- 元クリップ: `H:\マイドライブ\sns\XPost\<app>\01_raw_video\<場面>.mp4`（フォルダは新設してよい。app: sansu / kokugo / shakai / rika / eigo / shinshin / programming）
- 完成動画: `H:\マイドライブ\sns\XPost\<app>\03_video\`（既存の例: `kokugo\03_video\x_video_kokugo_full.mp4` = 4:5・26秒・音声なし・紙芝居式）
- 縦動画(9:16): `vertical_<app>_1080x1920.mp4`。X用(4:5): `x_video_<app>_motivation.mp4` など。
- 編集は `sns\ツール\vertical_video\make_vertical.py`（現状: スクショ紙芝居＋BGM。**実機クリップの取り込みは未実装**。PyAV でクリップを読み、角丸のスマホ枠に貼る処理を足す）。H.264 は PyAV の `libx264`・yuv420p で出力（`cv2` の avc1 は壊れる）。

## 5. 公開・申告の注意
- **Play プロモ動画**: YouTube URL を掲載に登録する。動画は一般公開または限定公開・広告オフ。**子ども向けの設定はユーザーが選択済み（「はい、子ども向けです」）**。コメント・通知は無効になる。
- **投稿の「広告なし・14日間無料」**: 算数・国語・理科・英語・心身・プログラミングの掲載文に反映済み（下書き）。公開済みなのは算数・国語のみ。他教科は「配信中」と書かない。
- 保護者ゲートの前に外部リンクを出さない（動画内でも、リンクを押す場面は映さない）。
- 投稿・アップロード・公開は、ユーザーの確認を取ってから。
