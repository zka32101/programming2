# 「ゲームで学ぶ都道府県」動画作成案
作成: 2026-10-09 / アプリ: geography_puzzle_king(pkg com.yourwish.japanprefecuresgame)/ **案のみ。撮影・投稿・公開は未実施。**

## 0. 前提(確認済みの事実)
- ジャンル: 都道府県の地理クイズ × タワーディフェンス。47都道府県それぞれに「ご当地ボス」(例: 北海道=ジャガイモ大王、青森=りんご騎士、大阪=たこ焼き大将)と相棒キャラ。
- 機能: 農業・漁業・工業・鉱業の施設を置いて防衛/県庁所在地・ボス名などのクイズ(クリア後に学習豆知識)/図鑑/実績・ランキング/本部強化。
- 料金: **無料で10県まで(広告つき)**。「プレミアム」(買い切り)で全47県＋広告非表示。会員登録不要。
- 状態: Play審査中(未公開)。**「配信中」とは言わない**。公開前は「準備中」「近日公開」表現にする。
- 小学コレシリーズ(広告なし)とは別物。**「広告なし」は無料版では言わない**(プレミアム時のみ)。
- 対象: 小学生(社会の地理)＋保護者。ゲーム好きの大人も二次ターゲット。

## 2. 構成案

## 3. 撮影方針(ハイブリッド)
- **実機の画面録画が主役**(タワーディフェンスは動きが命。静止画の紙芝居では伝わらない)。テンプレート編集は、テロップ・BGM・アウトロ・縦横変換のみ。
- 録画: 端末の画面録画(ユーザー操作)を推奨。`adb screenrecord` は不可(過去の知見)、scrcpyはカクつく。→ **端末標準の画面録画→PCへ転送**。4〜10秒の短いクリップを場面ごとに。
- ビルド: **release/profile**(debugはバナー・警告が映る)。明るい表示・テスト名を映さない(自然なニックネーム「はな」など)。
- 事前に: プロフィール作成→序盤の県をプレイ。10県(無料分)の範囲で撮る。**プレミアム解放は映さない/購入画面は映さない**(価格表示・購入導線は審査・表現の観点で避ける)。
- 端末は共用: 操作前に前面アプリを確認。
- 素材保存: `sns\XPost\toudoufuken\01_raw_video\<場面>.mp4`、完成は `…\03_video\`。

## 4. 編集・音
- 編集: `sns\ツール\vertical_video\make_vertical.py` をベースに、**実機クリップ取り込み機能を追加**(PyAVで読み、角丸のスマホ枠に貼る)。H.264は PyAV libx264 yuv420p。
- 音: 自作BGM・効果音(外部素材なし=ライセンス不要)。ボス登場・正解・制圧のSE。テンポは明るめ(128bpm)。
- テロップ: 大きめ(96px級)・1画面1行・ふりがな要否を学年に合わせて検討(小学生向けなので漢字にルビ案)。

## 5. 注意(表現・規約)
