# 実機確認チェックリスト（うかラボ共通基盤・bike／kanken）

対象: バイク免許コレ（kit v0.4.2 系／bike main）、漢字マスター検定（kit v0.4.3／kanken main）。
共用の実機なので、**始める前に前面のアプリを確認し、他のテストと重ならないようにする**。
各項目は ○（問題なし）／×（不具合）／－（確認できず）で記録し、×は画面と手順をメモする。

## 0. 準備
- [ ] 各アプリの最新 main から release ビルドを作る（`H:\マイドライブ\apk\` に保存。日本語パスのため英語パスのクローンでビルド）
- [ ] 署名違いの旧版が入っていないか確認（入っていればアンインストール。データは消える）
- [ ] 学習データのある状態と、初回起動（データなし）の状態の両方で見る

## 1. 推しカード（ホーム）— 両アプリ
- [ ] 推しが表示され、Lv が出る。学習コインの残高が出る
- [ ] 推しが動く（アニメーション）。画面が重くならない
- [ ] メニュー（︙）に「着替え・ショップ」「試験の結果を報告」が出る
- [ ] （bike）メニューの「通常／小さく表示／表示しない」が効き、再起動後も保たれる
- [ ] 習得度が上がると Lv が上がる（練習で数問解いて確認）

## 2. 「準備完了まで」カード（ホーム）— 両アプリ
- [ ] 推しカードの下にカードが出る（kanken は級を切り替えても追従する）
- [ ] 回答がない状態で「習得度があと80%、模擬試験の合格でそろいます」が出る
- [ ] 回答が増えると「あと◯%」が減る
- [ ] 習得度が足りた状態で模擬試験に合格すると「準備完了です」になる（または習得度は十分で模擬試験だけが残る文言）
- [ ] 責める・急かす文言がない

## 3. 着替え・ショップ — 両アプリ
- [ ] 画面が開く。衣装が並ぶ。ロック理由（「合格したときに解放されます」など）が出る
- [ ] コインが足りないとき、購入できない理由が分かる
- [ ] コインが足りるとき、通常衣装（300コイン）を購入でき、残高が減る
- [ ] 購入した衣装を着ると、ホームの推しに反映される
- [ ] 再起動しても購入・着用が保たれる

## 4. 試験の結果を報告（合格報告）— 両アプリ
- [ ] 「合格しました」: コインが増え、合格記念の衣装が付き、共有カードが出る（**1資格につき1回だけ**。2回目はコインが増えない）
- [ ] 「共有する」でOSの共有シートが開き、画像が相手アプリに渡る（実際に1つ送って見る）
- [ ] 共有画像に名前・メール・IDなどの個人情報がない
- [ ] 「今回は合格できなかった」: 責めない文言。コインも衣装も減らない
- [ ] 「まだ・結果待ち」: 何も起きない

## 5. 模擬試験 — 両アプリ
- [ ] 模擬試験を最後まで解ける（bike: 区分で48問／95問、kanken: 級ごと）
- [ ] 結果画面に「今回のコイン内訳」が出る（実施・合格で付与された分だけ）
- [ ] 合格点を超えたとき、「学習の記録カードを見る」が出る。超えないときは出ない
- [ ] 記録カードに「模擬試験」「本番の合格ではありません」が出る。コインも衣装も増えない
- [ ] 記録カードの「共有する」が動く。個人情報が入らない
- [ ] 準備完了の条件を満たした合格で、準備完了の衣装が解放される

## 6. 練習（kanken）
- [ ] 練習で初めて解く問題にコインが付く。同じ問題では付かない
- [ ] 練習を最後まで解くと終了画面に「今回のコイン内訳」が出る
- [ ] いったん戻って次の練習を始めると、前回の内訳が残っていない

## 7. 問題・標識（bike）
- [ ] 区分を切り替えても問題が出る（原付／小型限定／普通二輪／大型二輪／AT限定）
- [ ] 出典（教則・条文）が解説に出る問題がある。数十問を見て、事実の誤りに気づいたら控える
- [ ] 標識の図（追加分: Y字路・ロータリー・路面凸凹・上り下り勾配・吹流し・合流・車線減少・バス・幅員・横断歩道の並び・左折矢印・時間制限駐車）が崩れずに描かれる
- [ ] 色の取り違えがない（警戒=黄地黒、規制=白地赤枠または青地白）

## 8. アイコンと表示
- [ ] ランチャーのアイコンが新しい（bike: バイク、kanken: 漢字）。アダプティブアイコンで欠けない
- [ ] 暗いテーマ／明るいテーマの両方で、カード・ダイアログの文字が読める
- [ ] 横向き・文字を大きくした設定で崩れない

## 9. 通信・保存・権限
- [ ] 機内モードでも、推し・コイン・衣装・模擬試験が動く（端末内保存）
- [ ] 再起動・端末の再起動後も、コイン残高・衣装・合格報告が保たれる
- [ ] 想定外の権限要求が出ない（広告ID・位置情報・連絡先など）
- [ ] クラッシュ・ANR がない（`adb logcat` で `FATAL`・`ANR` を確認）

## 10. まだ実装・設定が済んでいないこと（確認対象外）
- Firebase Authentication（匿名・Google・Apple）の有効化はユーザー作業待ち。ログインを要する機能は確認できない
- 課金（RevenueCat／Play 商品）・AdMob の本番設定はユーザー作業待ち
- コイン・衣装の価格、習得度の式、無料／有料の衣装の分け方は暫定値
