# Avatar Prompts for 小学コレシリーズ

## 概要
全教科共通で使用するアバターキャラクター16個のLeonardo AIプロンプト集。
各キャラは **chibi-style, cute, friendly** デザインで、6-12歳向け教育アプリに最適化。

### 生成設定（共通）
- **モデル**: Leonardo Diffusion XL
- **解像度**: 512x512px
- **出力形式**: PNG (透過背景)
- **品質設定**: High (Steps: 20+)
- **スタイル**: Children's illustration, cute chibi style
- **背景**: Transparent
- **フォーカス**: Full body character, facing forward, friendly expression

## 使用例

### leonardo.ai での生成ステップ

1. **モデル選択**: Leonardo Diffusion XL
2. **プロンプト入力**: 上記プロンプトテキストをコピペ
3. **設定**:
   - Guidance Scale: 7.5-8.5 (バランスの取れた結果)
   - Steps: 20+ (高品質)
   - Style: Select "Illustration" or "Digital Art"
4. **生成**: Generate
5. **エクスポート**: PNG形式、512x512px を確認

### ファイル命名規則

生成後、以下の形式で保存：

```
shared_core/lib/assets/avatars/avatar_{id}.png
```

例：
- `avatar_honhon.png` (茶色クマ)
- `avatar_kuroneko.png` (黒猫)
- `avatar_panda.png` (パンダ)
- ...
- `avatar_namakemono.png` (ナマケモノ)

### 各教科での使用方法

```dart
// avatar_provider.dart (shared_core内)
final avatarList = [
```

## 統一デザイン原則

✅ **必須要素**
- Chibi-style (頭が大きく、体が小さい)
- Happy or neutral expression (常に親しみやすい)
- 大きな丸い目
- 明るい色彩
- 透過背景 PNG

✅ **統一性**
- すべて512x512px
- 全身が見える配置
- 正面向き
- 子ども向けイラストレーションスタイル

❌ **避けるべき要素**
- 怖い表情
- 暗い色
- 複雑すぎるデザイン
- リアルな動物の描写
