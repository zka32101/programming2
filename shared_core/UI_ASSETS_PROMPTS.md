## 概要

- **モデル**: Leonardo Diffusion XL
- **解像度**: 512x512px

- **スタイル**: Children's illustration, cute, educational game style
- **背景**: Transparent
- **用途**: 小学1-6年生向け教育ゲーム用UI要素
